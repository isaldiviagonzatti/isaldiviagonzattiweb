# isaldiviagonzattiweb

[Personal website](https://www.ignaciosg.com/)

## Development

The site is built with Astro and Node.js 22. From the repository root:

```sh
nvm use
npm install
npm run dev
```

Run `npm run build` to create the production site in `dist/`.

## Updating publications

The Publications page and the publication section of the web résumé share the same generated data. To refresh them after updating the public ORCID record, run:

```sh
npm run update:publications
```

The command reads journal articles and DOIs from ORCID, enriches their citation metadata with Crossref, and updates `src/data/publications.json`. It does not run during development, builds, or Netlify deploys. Review and commit the generated change when it looks correct.

Local PDF links, OSF links, and notes are maintained separately in `src/data/publicationExtras.ts`. The downloadable résumé PDF comes from the separate LaTeX résumé project and is not regenerated by this command.
